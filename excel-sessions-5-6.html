C1

Remove Duplicates

When the same record appears more than once — a customer entered twice, an order pasted in twice — Excel can find and delete the repeats automatically.

  1. Click any cell inside your data range.
  2. Go to Data tab → Remove Duplicates.
  3. Choose which columns must match for a row to count as a duplicate — Excel only deletes a row if every checked column matches another row exactly.
  4. Excel reports how many duplicate values it removed and how many unique values remain.
Before you run it: this deletes rows permanently once you close without undo. Copy your raw data to a backup sheet first, or duplicate the whole worksheet, so you always have the original to fall back on.
Why duplicates hide: "John Smith" and "John Smith " (trailing space) look identical but Excel treats them as different text — which is exactly why TRIM (next) usually runs before Remove Duplicates, not after.
C2

TRIM and other text-cleaning functions

Data copied from emails, PDFs, or web pages often carries invisible extra spaces or inconsistent capitalization. These functions fix that without retyping anything.

FunctionSyntaxWhat it fixes
TRIM=TRIM(A2)Removes leading/trailing spaces and collapses multiple spaces between words to one
CLEAN=CLEAN(A2)Strips non-printing characters often pasted in from other systems
PROPER=PROPER(A2)Capitalizes the first letter of each word — "john smith" → "John Smith"
UPPER / LOWER=UPPER(A2) / =LOWER(A2)Forces all-caps or all-lowercase, useful before comparing two text columns
=TRIM(PROPER(A2))  // clean spacing and capitalization in one step
Workflow: write the cleaning formula in a new column next to the messy one, check the results, then paste the new column back as values (Ctrl+Shift+V → Values Only) before deleting the original messy column.

Flash Fill

Flash Fill watches a pattern you start typing and completes the rest of the column automatically — no formula required. It's best for splitting, combining, or reformatting text based on an example.

  1. In the column next to your messy data, type the result you want for the first row by hand.
  2. Start typing the second row — Excel usually suggests the rest of the column in grey text.
  3. Press Enter to accept, or trigger it manually with Ctrl+E.
You haveYou typeFlash Fill produces
Priya SharmaPriya (first name only)Extracts first names down the column
priya@mail.compriyaExtracts text before the @ down the column
9876543210987-654-3210Reformats every phone number the same way
Limitation: Flash Fill results are static values, not live formulas — if the source data changes, Flash Fill does not update automatically. Re-run it if the source changes.
C4

Text-to-Columns

Use this when one column actually contains several pieces of data squeezed together — like "Hyderabad, Telangana" or "Rao, Priya" — and you need them split into separate columns.

  1. Select the column you want to split.
  2. Go to Data tab → Text to Columns.
  3. Choose Delimited (splits on a character like a comma or space) or Fixed Width (splits at fixed character positions).
  4. Pick the delimiter — comma, space, tab — and preview the split before confirming.
  5. Choose a destination cell so you don't accidentally overwrite adjacent columns.
Common use: splitting a "City, State" column into two separate columns so you can sort or filter by State alone.
C5

Sort

Sorting reorders rows based on the values in one or more columns — essential for spotting outliers, ranking results, or just making a table easier to scan.

  • Quick sort: click any cell in the column, then Data tab → Sort A→Z / Z→A.
  • Multi-level sort: Data tab → Sort opens a dialog where you can sort by Region first, then by Revenue within each region, using "Add Level."
  • Excel automatically expands the selection to keep whole rows together — always confirm "My data has headers" is checked so the header row itself doesn't get sorted into the data.
C6

Filter

Filtering hides rows that don't match a condition, without deleting anything — the data is still there, just temporarily out of view.

  1. Click any cell in your table, then Data tab → Filter (or Ctrl+Shift+L).
  2. Dropdown arrows appear on each header — click one to check/uncheck values, or use "Text Filters" / "Number Filters" for conditions like "greater than" or "contains."
  3. Filtered-out row numbers turn blue to remind you rows are hidden, not gone.
  4. Clear a filter from the same dropdown, or Data tab → Clear to reset every filter at once.
Filter vs. Sort: Sort changes row order permanently; Filter only changes what's visible. Use Filter first to isolate what you want to look at, then Sort within that view if needed.

D1

VLOOKUP

VLOOKUP looks up a value in the leftmost column of a table and returns a value from the same row, a specified number of columns to the right. It's the classic function for pulling a product's price from a separate price list.

=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])
=VLOOKUP(A2,Products!$A$2:$D$50,3,FALSE)  // find A2 in the Products table, return the 3rd column, exact match
ArgumentMeaning
lookup_valueThe value you're searching for — e.g. a Product ID
table_arrayThe full table to search, with the lookup column as its leftmost column — lock with $ so it doesn't shift when copied
col_index_numWhich column (counted from the left of table_array, starting at 1) holds the value you want returned
range_lookupFALSE = exact match (use this almost always); TRUE = approximate match, requires sorted data
Key limitation: VLOOKUP can only look to the right of the lookup column, and breaks if someone inserts or deletes a column inside the table (the col_index_num no longer points where you expect).
D2

XLOOKUP

XLOOKUP is the modern replacement for VLOOKUP — it can look in any direction, doesn't break when columns are inserted, and returns a clear result when nothing matches instead of an error.

=XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found])
=XLOOKUP(A2,Products!A:A,Products!C:C,"Not Found")  // search Product ID column, return the matching Price column
Difference from VLOOKUPWhy it helps
Points directly at the lookup column and the return column separatelyNo column counting — and it still works if columns are added or reordered
Can look left as well as rightThe value you want doesn't need to sit to the right of the value you're matching
Built-in if_not_found argumentShows a clean message instead of a #N/A error when there's no match
Exact match by defaultNo need to remember to type FALSE
Practical note: XLOOKUP is available in Excel 365 and Excel 2021+. If your workplace uses an older Excel version, INDEX-MATCH (next) is the fallback that works everywhere.
D3

INDEX-MATCH

INDEX-MATCH combines two functions to do what VLOOKUP does, without VLOOKUP's left-to-right restriction. MATCH finds the position of a value; INDEX returns the value at that position in another range.

=MATCH(lookup_value, lookup_array, 0)  // 0 = exact match; returns a row position, e.g. 7
=INDEX(return_array, row_number)  // returns the 7th value in return_array

Nested together, they become one lookup formula:

=INDEX(Products!C:C,MATCH(A2,Products!A:A,0))  // find A2's position in column A, return the matching value from column C
Why learn this if XLOOKUP exists? INDEX-MATCH works in every version of Excel ever made, and understanding it makes XLOOKUP's behavior easier to reason about — many workplaces still standardize on it for compatibility.
D4

Combining data from multiple tables

Lookup functions matter most when your data is split across sheets — a transactions sheet with just a Product ID, and a separate master sheet with product details — and you need to bring them together without copy-pasting by hand.

  1. Keep an ID column that exists identically in both tables (Product ID, Customer ID, Employee ID) — this is what you match on.
  2. Never duplicate the full product/customer details into your transactions sheet — look them up instead, so a single price update in the master sheet updates every transaction automatically.
  3. When pulling several fields (Name, Category, Price) from the same lookup, write one XLOOKUP or INDEX-MATCH per field, all matching on the same ID.
  4. Watch for IDs that don't match due to formatting — a text ID "1024" won't match a numeric 1024. TRIM and consistent formatting (Session 5) fix this before lookups run.
Debugging tip: if a lookup returns #N/A, check for exact-match spelling, extra spaces in the ID column, or numbers stored as text — these cause the vast majority of lookup errors.
D5

Practice activity: product lookup exercise

Build a two-table lookup workbook

  1. Create a sheet named Products with columns: Product ID, Product Name, Category, Unit Price. Add 15–20 products.
  2. Create a second sheet named Orders with columns: Order ID, Product ID, Quantity. Enter 20 orders, referencing Product IDs from the Products sheet — include at least one Product ID that does not exist in Products, to test error handling.
  3. On Orders, add a Product Name column using VLOOKUP to pull from Products.
  4. Add a Unit Price column using XLOOKUP, including an if_not_found message for the missing product.
  5. Add a Category column using INDEX-MATCH instead, so you practice all three methods on the same data.
  6. Add a Line Total column (Quantity × Unit Price) and sum it for a grand total.
  7. Compare: which of the three lookup methods was easiest to write? Which would break first if someone inserted a new column into the Products sheet?
