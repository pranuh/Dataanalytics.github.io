01

Aggregation — the basic summary numbers

Start here for any dataset
FunctionSyntaxExampleUse it for
SUM=SUM(range)=SUM(E2:E100)Total of a numeric column
AVERAGE=AVERAGE(range)=AVERAGE(D2:D100)Mean value — sensitive to outliers
MEDIAN=MEDIAN(range)=MEDIAN(D2:D100)Middle value — better than AVERAGE when outliers exist
COUNT=COUNT(range)=COUNT(C2:C100)How many cells hold numbers
COUNTA=COUNTA(range)=COUNTA(A2:A100)How many cells are non-blank (numbers or text)
COUNTBLANK=COUNTBLANK(range)=COUNTBLANK(B2:B100)Find missing data before analysis
MIN / MAX=MIN(range) / =MAX(range)=MAX(E2:E100)Smallest / largest value — spot extremes
SUBTOTAL=SUBTOTAL(function_num, range)=SUBTOTAL(9,E2:E100)Like SUM but ignores rows hidden by a Filter — use inside filtered tables
02

Conditional aggregation — summary numbers with a filter built in

The real analyst's toolkit
FunctionSyntaxExampleUse it for
SUMIF=SUMIF(range, criteria, sum_range)=SUMIF(B2:B100,"North",E2:E100)Total matching one condition
SUMIFS=SUMIFS(sum_range, range1, crit1, range2, crit2…)=SUMIFS(E2:E100,B2:B100,"North",A2:A100,"Notebook")Total matching two or more conditions at once
COUNTIF=COUNTIF(range, criteria)=COUNTIF(A2:A100,"Notebook")Count matching one condition
COUNTIFS=COUNTIFS(range1, crit1, range2, crit2…)=COUNTIFS(B2:B100,"North",C2:C100,">100")Count matching multiple conditions
AVERAGEIF=AVERAGEIF(range, criteria, avg_range)=AVERAGEIF(B2:B100,"South",D2:D100)Average of a subset that meets one condition
AVERAGEIFS=AVERAGEIFS(avg_range, range1, crit1, range2, crit2…)=AVERAGEIFS(D2:D100,B2:B100,"South",A2:A100,"Pen Set")Average of a subset that meets multiple conditions
MAXIFS / MINIFS=MAXIFS(max_range, range1, crit1…)=MAXIFS(E2:E100,B2:B100,"East")Highest/lowest value within a filtered subset
Rule of thumb: if the condition is on the same column you're summing, SUMIF is enough. The moment you need "Region = North and Product = Notebook," jump straight to SUMIFS/COUNTIFS/AVERAGEIFS.
03

Logical — decisions and error handling

Flags, tiers, and clean error messages
FunctionSyntaxExampleUse it for
IF=IF(test, if_true, if_false)=IF(C2>100,"High","Normal")Two-way decision
IFS=IFS(test1, val1, test2, val2…)=IFS(E2>10000,"Top",E2>5000,"Mid",TRUE,"Low")Many-way decision without nesting several IFs
AND=AND(test1, test2…)=IF(AND(C2>50,D2>75),"Pass","Fail")TRUE only if every condition holds
OR=OR(test1, test2…)=IF(OR(B2="North",B2="East"),"Zone1","Zone2")TRUE if any condition holds
NOT=NOT(test)=IF(NOT(B2="Closed"),"Active","Closed")Reverses a TRUE/FALSE result
IFERROR=IFERROR(formula, value_if_error)=IFERROR(VLOOKUP(A2,Prod!A:D,3,FALSE),"Not Found")Replace any error with a clean message
IFNA=IFNA(formula, value_if_na)=IFNA(XLOOKUP(A2,ID,Name),"No Match")Same as IFERROR but only catches #N/A, not all errors
04

Lookup & reference — combining tables

Pulling matching data across sheets
FunctionSyntaxExampleUse it for
VLOOKUP=VLOOKUP(lookup, table, col_num, FALSE)=VLOOKUP(A2,Products!A:D,3,FALSE)Standard lookup — only searches left to right
HLOOKUP=HLOOKUP(lookup, table, row_num, FALSE)=HLOOKUP(A2,Rates!A1:F5,3,FALSE)Same as VLOOKUP but for data laid out in rows instead of columns
XLOOKUP=XLOOKUP(lookup, lookup_array, return_array, [if_not_found])=XLOOKUP(A2,Products!A:A,Products!C:C,"N/A")Modern lookup — any direction, no column counting, clean not-found handling
INDEX=INDEX(array, row_num, [col_num])=INDEX(C2:C100,7)Returns the value at a given position in a range
MATCH=MATCH(lookup, array, 0)=MATCH(A2,Products!A:A,0)Returns the position of a value — combine with INDEX
INDEX+MATCH=INDEX(return_col,MATCH(lookup,lookup_col,0))=INDEX(Products!C:C,MATCH(A2,Products!A:A,0))Works in every Excel version; looks either direction
CHOOSE=CHOOSE(index_num, val1, val2…)=CHOOSE(2,"Low","Mid","High")Pick from a short fixed list by position number
05

Text cleanup — before analysis can start

Fixing messy source data
FunctionSyntaxExampleUse it for
TRIM=TRIM(text)=TRIM(A2)Removes extra/leading/trailing spaces
CLEAN=CLEAN(text)=CLEAN(A2)Strips non-printing characters from pasted data
PROPER / UPPER / LOWER=PROPER(text)=PROPER(A2)Standardize capitalization before comparing text
LEFT / RIGHT / MID=LEFT(text,n) / =MID(text,start,n)=LEFT(A2,3)Extract a fixed number of characters from a string
LEN=LEN(text)=LEN(A2)Character count — catch truncated or malformed entries
FIND / SEARCH=FIND(find_text, within_text)=FIND("@",A2)Position of a character — SEARCH ignores case, FIND doesn't
SUBSTITUTE=SUBSTITUTE(text, old, new)=SUBSTITUTE(A2,"-","")Replace every occurrence of a character or word
CONCAT / TEXTJOIN=TEXTJOIN(delim, ignore_empty, range)=TEXTJOIN(", ",TRUE,A2:C2)Combine multiple columns into one, with a chosen separator
TEXT=TEXT(value, format)=TEXT(E2,"#,##0.00")Convert a number/date into formatted text for reports
06

Date & time — trend and cohort analysis

Turning timestamps into usable periods
FunctionSyntaxExampleUse it for
TODAY / NOW=TODAY() / =NOW()=TODAY()Current date / current date+time, updates automatically
YEAR / MONTH / DAY=YEAR(date)=YEAR(A2)Extract a date part for grouping (e.g. sales by month)
DATEDIF=DATEDIF(start, end, unit)=DATEDIF(A2,B2,"D")Days/months/years between two dates — e.g. customer tenure
EOMONTH=EOMONTH(start_date, months)=EOMONTH(A2,0)Last day of the month — useful for month-end reporting cutoffs
WORKDAY=WORKDAY(start_date, days)=WORKDAY(A2,10)Add business days, skipping weekends
NETWORKDAYS=NETWORKDAYS(start, end)=NETWORKDAYS(A2,B2)Count business days between two dates
07

Rounding & math — clean numbers for reporting

Precision control
FunctionSyntaxExampleUse it for
ROUND=ROUND(number, digits)=ROUND(E2,2)Round to a set number of decimal places
ROUNDUP / ROUNDDOWN=ROUNDUP(number, digits)=ROUNDUP(E2,0)Force rounding direction — e.g. always round up units needed
ABS=ABS(number)=ABS(B2-B3)Absolute difference regardless of which value is larger
SUMPRODUCT=SUMPRODUCT(range1, range2)=SUMPRODUCT(C2:C100,D2:D100)Multiply two ranges element-by-element and sum — weighted totals
08

Ranking & distribution — where a value stands

Comparing one row to the whole dataset
FunctionSyntaxExampleUse it for
RANK.EQ=RANK.EQ(number, range, [order])=RANK.EQ(E2,$E$2:$E$100,0)Rank a value against the full dataset (0 = descending)
PERCENTILE.INC=PERCENTILE.INC(range, k)=PERCENTILE.INC(E2:E100,0.9)Value at the Nth percentile — e.g. top 10% cutoff
STDEV.S=STDEV.S(range)=STDEV.S(E2:E100)Spread/variability of a sample — flag unusually inconsistent data
MODE.SNGL=MODE.SNGL(range)=MODE.SNGL(C2:C100)Most frequently occurring value
09

Dynamic arrays — modern Excel (365 / 2021+)

Spill formulas that replace helper columns
FunctionSyntaxExampleUse it for
UNIQUE=UNIQUE(range)=UNIQUE(A2:A100)List distinct values — e.g. unique customer names, no duplicates
SORT=SORT(range, col, order)=SORT(A2:E100,5,-1)Sort a range with a formula instead of the Data tab, updates live
FILTER=FILTER(range, condition)=FILTER(A2:E100,B2:B100="North")Pull matching rows into a new location, updates automatically
SORTBY=SORTBY(range, by_range, order)=SORTBY(A2:A100,E2:E100,-1)Sort one range by the values in a different range
SEQUENCE=SEQUENCE(rows, [cols], [start], [step])=SEQUENCE(12,1,1,1)Auto-generate a numbered list — e.g. month numbers 1–12
Note: these require Excel 365 or Excel 2021+. On older versions, replicate UNIQUE with Remove Duplicates, and FILTER with the Filter tool from Session 5.
