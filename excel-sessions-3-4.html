A1

Workbook vs. worksheet

A workbook is the entire Excel file (the .xlsx) you save on disk. A worksheet (or "sheet") is one page inside that file, made of a grid of rows and columns. A single workbook can hold many worksheets — for example, one tab for raw sales data, one for a summary, and one for charts.

  • Columns are labeled with letters (A, B, C … Z, then AA, AB …).
  • Rows are labeled with numbers (1, 2, 3 …).
  • Each box where a row and column meet is a cell, identified by its address — e.g. C4 means column C, row 4.
  • Sheet tabs sit at the bottom of the window; double-click a tab to rename it, right-click to add, delete, or color-code sheets.
Why it matters: when you analyze data later, you'll often keep raw data on one sheet and build summaries on another — so formulas need to reference cells across sheets, written as SheetName!A1.

Formatting a worksheet

Formatting changes how data looks without changing the underlying value. Good formatting makes a sheet readable at a glance — this matters as much as the formulas themselves.

TaskWhere to find it
Bold, italic, font size, colorHome tab → Font group
Number, currency, percentage, date formatsHome tab → Number group, or Ctrl+1
Cell fill color / bordersHome tab → Font group (paint bucket icon, border icon)
Column width / row heightDrag the border between headers, or double-click to auto-fit
Merge & center a title across columnsHome tab → Alignment group
Freeze header row so it stays visible while scrollingView tab → Freeze Panes → Freeze Top Row
Habit to build: format your header row (bold text, a fill color, freeze it) before you enter any data. It costs ten seconds now and saves confusion later.
A3

Cell references

A cell reference is how a formula points to a value instead of retyping it. Excel has three types, and the difference only shows up when you copy a formula to other cells.

TypeWritten asBehavior when copied
RelativeA2Shifts automatically — copying =A2*2 from row 2 to row 3 becomes =A3*2.
Absolute$A$2Stays locked to A2 no matter where you copy it. Use for a fixed value like a tax rate.
Mixed$A2 or A$2Locks only the column or only the row — useful in tables where one axis should stay fixed.

Press F4 right after typing a reference to cycle through relative → absolute → mixed → mixed, instead of typing dollar signs by hand.

=B2*$D$1  // B2 shifts when copied; $D$1 (e.g. a fixed commission rate) never does
A4

Writing formulas

Every formula starts with an equals sign. Excel calculates it and shows the result in the cell, while the formula itself stays visible in the formula bar when that cell is selected.

  • Basic arithmetic: =A2+B2, =A2-B2, =A2*B2, =A2/B2
  • Order of operations follows normal math rules — use parentheses to control it: =(A2+B2)*C2
  • Reference another sheet: =Sales!B2
  • Click a cell instead of typing its address — Excel inserts the reference for you and it's less error-prone
Common mistake: typing a formula's result by hand instead of a formula. If you type 450 instead of =B2+C2, the number won't update when B2 or C2 changes.

B1

SUM, AVERAGE, COUNT

These three answer the most common questions about a range of numbers: total, typical value, and how many entries there are.

FunctionSyntaxWhat it returns
SUM=SUM(range)The total of all numbers in the range
AVERAGE=AVERAGE(range)The mean of the numbers in the range
COUNT=COUNT(range)How many cells in the range contain numbers
COUNTA=COUNTA(range)How many cells contain anything at all (numbers or text) — useful for counting entries like employee names
=SUM(E2:E13)  // total revenue
=AVERAGE(D2:D13)  // average unit price
=COUNTA(A2:A13)  // number of sales entries
B2

MIN, MAX

MIN and MAX pull out the smallest and largest values in a range — useful for spotting your best and worst performers without scrolling through every row.

=MAX(E2:E13)  // highest single revenue value
=MIN(E2:E13)  // lowest single revenue value

To find which product produced that maximum, combine it with INDEX/MATCH later on — for now, it's enough to locate the value and check the row manually.

B3

IF

IF tests a condition and returns one value if it's true, another if it's false. It's the building block for almost every decision rule you'll build in a spreadsheet.

=IF(logical_test, value_if_true, value_if_false)
=IF(C2>100,"High Volume","Normal")  // flag rows where Units Sold exceeds 100

IFs can be nested to handle more than two outcomes:

=IF(E2>10000,"Top Tier",IF(E2>5000,"Mid Tier","Standard"))
B4

AND, OR

AND and OR combine multiple conditions. They return TRUE or FALSE on their own, which is why they're almost always nested inside an IF.

FunctionReturns TRUE when
ANDevery condition given is true
ORat least one condition given is true
=IF(AND(C2>50,D2>200),"Bonus Eligible","Not Eligible")  // both conditions must hold
=IF(OR(B2="North",B2="East"),"Zone 1","Zone 2")  // either condition is enough
B5

SUMIF, COUNTIF

These add a condition directly into SUM and COUNT, so you don't need an IF column to filter first.

=SUMIF(range, criteria, [sum_range])
=COUNTIF(range, criteria)
=SUMIF(B2:B13,"North",E2:E13)  // total revenue for the North region only
=COUNTIF(A2:A13,"Notebook")  // how many rows sold Notebooks

If a condition depends on more than one column (e.g. Region and Product), use SUMIFS and COUNTIFS, which take multiple range/criteria pairs — worth a quick look once these two feel comfortable.
